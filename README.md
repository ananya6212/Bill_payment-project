# BillBook

A fast, simple web-based billing and inventory management app.

## Features

- Dashboard
- Product and inventory management
- Customer invoices
- Invoice history
- Automatic subtotal, discount and tax calculation
- Stock management
- Store settings
- Invoice generation
- PDF invoice support

## Technology

- Python
- FastAPI
- SQLAlchemy
- Jinja2
- HTML
- CSS
- JavaScript
- SQLite

## Running Locally

Create and activate a virtual environment, install the dependencies and run the FastAPI application.

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
